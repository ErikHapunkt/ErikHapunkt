# B2B Growth Case Study — Erik Husser

A static portfolio website presenting documented responsibilities from my role as Sales Manager at Univents, an event management software start-up (July 2023–January 2024).

## What this project does

- Presents market segmentation, target-group analysis and competitor research.
- Describes SEO/SEA as part of target-group-specific sales strategies.
- Connects B2B lead generation with CRM pipeline management and sales-funnel work.
- Separates CV-supported responsibilities from unknown historical performance data.
- Provides a clearly labelled *proposed* measurement framework for future campaigns.

## Evidence and limitations

The experience descriptions are based on my CV. Google/Meta Ads experience is described only as some practical experience; this page does not claim independent ownership of specific campaigns. I have advanced SEO knowledge. I do not claim analytics/reporting experience. Historical project KPIs are unknown and are not fabricated.

The measurement plan is a hypothetical recommendation for future work, not a report of work completed at Univents.

## Run locally

Open `index.html` in a browser.

## Publish with GitHub Pages

1. Create a repository named `b2b-growth-case-study`.
2. Upload `index.html`, `styles.css`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. Wait for GitHub to publish the page and use the URL shown in Pages settings.

This archive contains the website files; it does not create or publish a GitHub repository automatically.
